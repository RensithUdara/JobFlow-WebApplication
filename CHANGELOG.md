# Changelog

All notable changes to JobFlow are documented here.

## Unreleased

### Added

- Go API for authentication, jobs, queues, workers, dashboard stats, and realtime events
- Redis-backed job queue
- PostgreSQL persistence
- Worker pool with configurable concurrency
- Scheduled job promotion
- Retry and dead-letter handling
- React dashboard with Jobs, Queues, Workers, Dashboard, and Settings views
- Light and dark theme support
- Fixed sidebar layout
- Custom confirmation dialog
- Saved job drafts
- JSON import for job creation
- Job analytics panel
- JobFlow logo and favicon
- Full README and documentation files

### Changed

- UI displays readable names instead of raw internal IDs where possible
- Dark theme contrast and form control colors improved
- Search focus styling improved
